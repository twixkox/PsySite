# PsySite

PsySite — личный сайт психолога на ASP.NET Core. Проект объединяет публичные страницы специалиста,
публикацию материалов, запись на консультации и административную панель для управления контентом.

## Основные возможности

- Главная страница, сведения о специалисте, проекты, статьи и события.
- Публикация и редактирование материалов через административную панель.
- Расписание консультаций, свободные временные окна и запись клиентов.
- Управление типами консультаций, страницами, статьями и записями.
- Подписка посетителей на новости и материалы.
- Уведомления по электронной почте.
- Журнал работы сайта и история действий администратора.
- Адаптивный интерфейс без тяжёлых клиентских фреймворков.

## Стек

- **C#, .NET 10, ASP.NET Core MVC** — серверная часть приложения.
- **Razor, HTML, CSS, JavaScript** — страницы и клиентский интерфейс.
- **Entity Framework Core** — работа с базой данных.
- **SQLite / PostgreSQL / Microsoft SQL Server** — поддерживаемые СУБД.
- **Serilog** — журналирование и ротация файлов журналов.
- **Docker, Docker Compose** — контейнерное развёртывание.

## Структура

```text
PsySite/
├── Areas/Admin/              # Административная панель
├── Controllers/              # Контроллеры публичной части
├── Data/                     # Контекст, инициализация и настройка базы данных
├── Logging/                  # Настройка и чтение журналов
├── Models/                   # Модели данных
├── Security/                 # Правила и компоненты безопасности приложения
├── Services/                 # Прикладные сервисы
├── Views/                    # Razor-представления
├── wwwroot/                  # Стили, скрипты и изображения
├── deploy/                   # Материалы для развёртывания на IIS
├── Dockerfile
├── docker-compose.yml
└── PsySite.csproj
```
