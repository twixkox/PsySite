# 🧠 PsySite — личный сайт психолога

Сайт специалиста на **ASP.NET Core MVC**, объединяющий:
- публичные страницы и публикацию материалов;
- проекты, тексты, события и записи вебинаров;
- расписание и запись на консультации;
- подписку на новости;
- административную панель для управления сайтом.

## Возможности

### Для посетителей
- **Публичные страницы.** Главная, сведения о специалисте, контакты и тематические страницы.
- **Материалы.** Проекты, статьи, события и записи вебинаров с отдельными страницами.
- **Запись на консультацию.** Выбор формата, даты и свободного времени, заполнение контактных данных.
- **Подписка.** Форма подписки на новые материалы и новости специалиста.
- **Уведомления.** Письма о записи и изменениях её состояния.
- **Адаптивная версия.** Удобная навигация и чтение материалов на мобильных устройствах.

### Для владельца сайта
- Редактирование текстовых страниц и основных сведений о специалисте.
- Публикация и изменение материалов через редактор контента.
- Управление проектами, статьями, событиями и записями вебинаров.
- Настройка типов консультаций и расписания свободных окон.
- Просмотр, подтверждение, отметка о проведении и отмена записей.
- Список подписчиков и выгрузка данных.
- Журнал работы сайта и история действий в административной панели.

## Запись на консультацию

1. В административной панели создаются типы консультаций и свободные временные окна.
2. Посетитель выбирает подходящий формат, дату и время.
3. После заполнения формы создаётся запись, а выбранное время закрепляется за клиентом.
4. Владелец сайта видит запись в панели управления и может изменить её состояние.
5. Клиент и владелец сайта получают уведомления по электронной почте.

Свободные окна можно создавать на отдельную дату или по расписанию на период. Повторная запись
на уже занятое время ограничивается на уровне приложения и базы данных.

## Контент и структура сайта

Основные адреса:

| Адрес | Раздел |
|---|---|
| `/` | Главная страница |
| `/projects` | Проекты |
| `/texts` | Статьи и тексты |
| `/events` | События |
| `/webinars` | Записи вебинаров |
| `/consultations` | Запись на консультацию |
| `/admin` | Административная панель |

Контент хранится в базе данных и редактируется без изменения исходного кода. Для материалов
используются человекочитаемые адреса, изображения, описания и порядок публикации.

## Интерфейс

- Серверный рендеринг страниц через **Razor**.
- Собственное оформление на CSS без тяжёлых клиентских фреймворков.
- Адаптивная навигация и формы для мобильных устройств.
- Визуальный редактор материалов в административной панели.
- Отдельные шаблоны публичной части и панели управления.
- Понятные сообщения об ошибках и страницы состояний.

## Технологии

### Backend
- C#, .NET 10
- ASP.NET Core MVC и Razor
- Entity Framework Core
- SQLite, PostgreSQL или Microsoft SQL Server
- Serilog — структурированные журналы и ротация файлов
- Фоновые и прикладные сервисы для записей, уведомлений и работы с контентом

### Frontend
- HTML, CSS и JavaScript
- Razor View Components и частичные представления
- Адаптивная вёрстка без отдельного SPA-фреймворка

### Инфраструктура
- Docker и Docker Compose
- Профили публикации и сценарии развёртывания на IIS

## Структура проекта

```text
PsySite.csproj
├── Areas/Admin               # Административная панель
│   ├── Controllers           # Управление контентом и записями

└── docker-compose.yml
```

## Установка и запуск

### Через Docker

```bash
git clone https://github.com/twixkox/PsySite.git
cd PsySite
cp .env.example .env
```

Заполните локальный файл `.env`, затем выполните:

```bash
docker compose up --build
```

Сайт будет доступен по адресу `http://localhost:8082`. База данных, журналы и загруженные
изображения сохраняются в Docker-томах.

### Локально

1. Установите [.NET 10 SDK](https://dotnet.microsoft.com/download).
2. Запустите проект:

```bash
dotnet run
```

3. Откройте `https://localhost:5001` или адрес из вывода команды.

При первом запуске создаётся база SQLite и добавляются начальные материалы. Их можно изменить
или удалить через административную панель.

## База данных

По умолчанию используется **SQLite**, поэтому для локального запуска отдельная СУБД не нужна.
Также поддерживаются PostgreSQL и Microsoft SQL Server.

| Провайдер | Назначение |
|---|---|
| **SQLite** | Локальная разработка и небольшой сайт без отдельного сервера БД |
| **PostgreSQL** | Развёртывание на Linux-сервере |
| **Microsoft SQL Server** | Инфраструктура Windows или существующий SQL Server |

Выбор провайдера и строка подключения задаются в конфигурации приложения. Файл базы SQLite,
загруженные изображения и ключи приложения хранятся отдельно от исходного кода.

## Журналирование

Serilog записывает запросы, ошибки, запуск приложения и действия административной панели.
Для журналов предусмотрены:

- отдельные файлы обычных событий и ошибок;
- ежедневная ротация и ограничение размера файлов;
- настраиваемый срок хранения;
- просмотр и поиск записей в административной панели;
- маскирование персональных данных в сообщениях.
